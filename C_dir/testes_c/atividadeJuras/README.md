1) Escreva um programa que declare uma variável inteira, um ponteiro para inteiro, atribua o endereço da variável ao ponteiro e imprima:
      a) O valor da variável.
      b) O endereço da variável.
      c) O valor armazenado no ponteiro.

2) Crie um programa que use um ponteiro para alterar o valor de uma variável inteira.

3) Crie uma função que troque o valor de duas variáveis inteiras usando ponteiros.

4) Escreva um programa que mostre o valor e o endereço de uma variável float usando ponteiros.

5) Crie uma função que receba um ponteiro para inteiro e multiplique o valor por 2.
